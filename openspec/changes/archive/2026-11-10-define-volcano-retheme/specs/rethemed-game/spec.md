# Spec Delta

## Purpose

Give players a second game on the Volcano machine with its own rules and play experience.

## ADDED Requirements

### Requirement: Play a distinct ruleset
The rethemed game SHALL offer a complete game with its own objectives, scoring, and progression on the Volcano playfield.

#### Scenario: A player starts the rethemed game
- **WHEN** a player starts the rethemed game and plays through a session
- **THEN** the machine runs that game's objectives, scoring, progression, and completion rules from the first ball through game over
